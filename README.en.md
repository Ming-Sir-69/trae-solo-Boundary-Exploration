# Trae SOLO Scenario Exploration Archive

## Purpose

Archives exploration reports, preview examples and multi-format artifacts for six simulated task categories in Trae SOLO Code/MTC modes.

## Repository guide

| Entry | Contents |
| --- | --- |
| [Exploration report](outputs/00_Trae_SOLO能力测试总报告.md) | Overall reading entry |
| [Modes and scenarios](outputs/Q1_模式与场景分析.md) | Scenario-analysis record |
| [Subagent system](outputs/Q2_子代理体系.md) | Recorded collaboration exploration |
| [Tool inventory](outputs/Q3_工具清单.md) | Tool-use record |
| [File-preview report](outputs/Q4_文件预览测试/预览测试报告.md) | Stored format examples and records |
| [Presentation outputs](outputs/ppt_assets/ppt_output/) | Existing PPT artifacts |
| [Charts](outputs/ppt_assets/charts/) | Chart assets |
| [Development background](README_DEV.md) | Six-scenario notes and future directions |

## Getting started

1. Start with the overall report, then select records by mode, collaboration or file format.
2. Read Markdown on the Code page and download presentations and charts for viewing.
3. Use the development notes to understand simulated inputs and the purpose of the artifacts.

## Scope and limitations

- There is no root application entry or unified dependency list, so no speculative startup command is supplied.
- Scenarios use mock/simulated inputs; ratings and demonstrations are historical exploration records rather than general benchmarks for the current version.
- The `project_context/` referenced by old development notes is absent from the actual tree; use the real paths listed here.
